## Your Supabase Tokens

::: {.tabset}

# Unauthenticated Calls

For calls that do not require a JWT, set **Authentication** to `apikey` and paste your `NEXT_PUBLIC_SUPABASE_ANON_KEY`. Test Request sends it as the `apikey` header.

# Authenticated Calls 

::: {.callout}
# Auth Required {.lock} calls need Authentication `apikey` plus `bearerAuth` set to your admin session token (`authenticated`). 

The catalog lists every HTTP method PostgREST knows:

- The guestbook only grants the verbs the app uses, so some sends return `42501` even with a valid JWT. 
- Do not paste `service_role` into the browser — Supabase will reject it, not return a useful response, and advise you to regenerate your `service_role` key.
- If a call has a note under its heading, that method is not testable through the explorer.

:::

To test the authenticated calls with this page, you'll need retrieve your admin JSON Web Token (JWT). 

Since it's tied to your admin login, it's kind of hacky to snag. For example, in Chrome:

1. Login to your guestbook admin dashboard.

2. Open Developer Tools in your browser (`F12` or `right-click `> **Inspect**).

3. Click **Console**.

4. If you've never pasted into your terminal before, you might need to enable pasting first. 
    
    In the terminal, type **allow pasting** and press Enter.

5. Paste the following command and press Enter:

    ```javascript
    (() => {
    const chunks = document.cookie.split("; ")
        .map((row) => {
        const i = row.indexOf("=");
        return [row.slice(0, i), decodeURIComponent(row.slice(i + 1))];
        })
        .filter(([name]) => name.includes("-auth-token") && !name.includes("code-verifier"))
        .sort(([a], [b]) => a.localeCompare(b, undefined, { numeric: true }));
    const joined = chunks.map(([, value]) => value).join("");
    const encoded = joined.startsWith("base64-") ? joined.slice(7) : joined;
    const session = JSON.parse(atob(encoded.replace(/-/g, "+").replace(/_/g, "/")));
    copy(session.access_token);
    return session.access_token;
    })();
    ```

6. Right click and select **Copy string contents** to copy the output to your clipboard.

7. When you're in the **Test Request** form, or after you set your Supabase Project ID in the section below, open **Authentication**:

    a. Select `apikey` and enter your `NEXT_PUBLIC_SUPABASE_ANON_KEY`.
    b. Select `bearerAuth` and enter your `Bearer Token: <your-admin-auth-token>`.

8. Click **Send**.
