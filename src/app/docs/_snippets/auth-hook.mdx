### Enable Authentication Hook

::: {tabset}

# 1. Run Installation Schema

a. Copy the contents of [`schema.sql`](https://github.com/beck-chan/y2k-guestbook/blob/main/scripts/schema.sql){.blank} to your clipboard.

b. Within Supabase, select **SQL Editor** from the left sidebar, then paste in the contents of `schema.sql`.

c. Click **Run** to execute the schema.

d. If you receive a Potential issue detected popup, click **Run query** to execute the schema. 

::: {.callout}
Confirm that you see `Success. No rows returned` under the Results before moving on to the next step.
:::

# 2. Set Up Auth Hook

a. Within Supabase, select **Authentication** from the left sidebar, then click **Auth Hooks**.

b. Click **Add hook**, then select **Before User Created hook**:

    - For **Hook type** select `Postgres`.
    - For **Postgres Schema**, select `schema.public`.

c. For **Postgres funtion**, select `function: hook_before_user_created`.

d. Click **Create hook**.

# 3. Set Up Redirects

a. Within Supabase, select **Authentication** from the left sidebar, then click **URL Configuration**.

b. Confirm that `http://localhost:3000` is already entered under **Site URL** for local previews and builds.

c. (Optional, for deployment builds) To enter a redirect URL for deployment:

    i. Under Redirect URLs, click **Add URL**.

    ii. Paste in your deployment callback URL. This is your `SITE_URL` with `auth/callback` appended to the end.

        For example: `https://<your-project-url>.vercel.app/auth/callback`.

    iii. Click **Save URLs**.

:::
