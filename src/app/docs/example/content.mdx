# MDX Reference

To build only the documentation for previewing:

```bash
npm run docs
```

::: {.callout}

Copy `example/page.tsx` next to a `content.mdx` into a directory named for the page URL slug.

Navigation with sections linked to the documentation landing page is defined in `src/app/docs/_nav/docs-nav-data.ts`.

## YAML Frontmatter

```yaml
---
subtitle: Set an optional subtitle
search: false # Hide page from docs search
public: false # Hide page when FLAG_PUBLIC=true

# h1 sets the page title and browser tab
---
```

## Single-Sourcing

Shared prose lives in `_snippets/`. Import a snippet to use it on a page:

```markdown
import Example from "../_snippets/example.mdx"

<Example />
```

::: {.callout}
<Example />
:::

Leave YAML and `# h1` on the host page. Snippet `##` / `###` headings are included in the host table of contents automatically, in the order the snippet appears on the page.

### Conditional Content

`public: false` in YAML hides an entire page when `FLAG_PUBLIC=true`. Leave it off and the page will display in both builds. 

To swap a chunk, not the page, use a fence — copy outside fences is always shown regardless of flags.  The other fence is dropped at compile time, including its headings. 

- `{.public}` is kept when `FLAG_PUBLIC=true`
- `{.private}` is kept when `FLAG_PUBLIC=false`


```markdown
::: {.public}
Public-build copy (`FLAG_PUBLIC=true`).
:::

::: {.private}
Custom-install copy (`FLAG_PUBLIC=false`).
:::
```

::: {.callout}

::: {.private}
This sentence is the private variant — compiled in when `FLAG_PUBLIC=false`.
:::

::: {.public}
This sentence is the public variant — compiled in when `FLAG_PUBLIC=true`.
:::

:::

For longer or generated copy, keep a sibling pair next to the host file and embed it. Shared `_snippets` imports are not rewritten. `.ts`, `.sql`, and `.feature` siblings render as a highlighted code block. 

- Unmarked `name.mdx` is the private file
- `name-public.mdx` is the public file

A missing pair file fails the build. 


```markdown
::: {.embed src="conditional-embed"}
:::
```

::: {.callout}

::: {.embed src="conditional-embed"}
:::

:::

`src` is relative to the file that contains the fence. Headings inside an embedded `.mdx` join the host table of contents.

### Callouts

### Tables

Pipe tables use a header row, a `| --- |` separator, and body rows:

| Data | Who | Purpose |
| --- | --- | --- |
| Display name and message body | Anyone who posts | Show guestbook comments |
| Optional email (if the email field is enabled) | Comment authors | Visible to site admins only |
| IP address (stored hashed) | Comment submitters | Rate-limit abuse |

Align a column with `:---` (left), `:---:` (center), or `---:` (right) in the separator row.
