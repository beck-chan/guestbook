# Add Analytics

Use PostHog to track page views and user interactions, as well as to show a visitor hit counter in your production build.

::: {.callout}
This guide assumes:

- [x] You've set up the guestbook application with either [Quickstart](/docs/quickstart) or [Install via npm](/docs/install).
- [x] You already have a PostHog account and project.
- [x] (For cloud deployment) You have a Vercel account and project.
:::

## PostHog Setup

### Retrieve PostHog Variables

From the [PostHog](https://posthog.com/){.blank} dashboard's left sidebar, click **Settings**:

::: {.tabset}

# 1. Retrieve Project Details

 Under Settings - General:

a. Copy your **Project token**. Enter this into your `.env.local` file under your `NEXT_PUBLIC_POSTHOG_KEY`:
    
    ```bash
    NEXT_PUBLIC_POSTHOG_KEY=<your-project-token>
    ```

b. Under SDK setup, grab the `api_host` value from one of the snippets (For example, `https://us.i.posthog.com`). Enter this into your `.env.local` file under your `NEXT_PUBLIC_POSTHOG_HOST`:
    
    ```bash
    NEXT_PUBLIC_POSTHOG_HOST=<your-project-api-host>
    ```

c. Copy your **Project ID**. Enter this into your `.env.local` file under your `POSTHOG_PROJECT_ID`:
    
    ```bash
    POSTHOG_PROJECT_ID=<your-project-id>
    ```

# 2. Create Personal API Key

a. In the Settings left sidebar, select **Personal API keys** under Account.

b. Click **+ Create personal API key**.

c. Give the key a **Label**. For example: `Guestbook Hit Counter`

d. Under **Organizations & project access**, select **Projects** then the project you want to grant access to.

e. Under **Scopes**, select **Query**: `Read`.

f. Click **Create key**.

    i. Copy your API key after it generates. Enter this into your `.env.local` file under your `POSTHOG_PERSONAL_API_KEY`:

        ```bash
        POSTHOG_PERSONAL_API_KEY=<your-personal-api-key>
        ```

    ii. For your `POSTHOG_API_HOST`, enter the app host for the Query API (For example: `https://us.posthog.com`, not the `*.i.posthog.com` ingest host):

        ```bash
        POSTHOG_API_HOST=<your-api-host>
        ```

:::

### Configure PostHog

For cloud deployment:

::: {.tabset}

# 1. Enter Vercel Variables

If you are deploying to Vercel:

a. In the left sidebar of your guestbook project, select **Environment Variables**.

b. Click **Add Environment Variable**.

c. Enter the following as **Config** Type variables:

    ```bash
    NEXT_PUBLIC_POSTHOG_KEY=<your-project-token>
    NEXT_PUBLIC_POSTHOG_HOST=<your-project-api-host>
    FLAG_COUNTER=true
    # End `FLAG_COUNTER_URL` with a trailing slash for one exact page
    FLAG_COUNTER_URL=https://<your-project-url>.vercel.app/
    # Use PostHog UTC time: `YYYY-MM-DD HH:mm:ss` (or `YYYY-MM-DD` for midnight)
    # Leave `FLAG_COUNTER_DATE` empty to count all time
    FLAG_COUNTER_DATE=2026-09-16 00:00:00
    ```

d. Enter the following as **Secret** Type variables:

    ```bash
    # IMPORTANT: MAKE SURE THEY ARE SECRET SO THEY ARE HIDDEN
    POSTHOG_PERSONAL_API_KEY=<your-personal-api-key>
    POSTHOG_PROJECT_ID=<your-project-id>
    POSTHOG_API_HOST=<your-api-host>
    ```

# 2. Configure Web Analytics URLs

a. From the PostHog dashboard's left sidebar, click **Settings**.

b. Under Products, select **Web analytics**.

c. Under **Web analytics domains**, click **+ Add new authorized URL**.

d. Enter in the URL of your deployed guestbook application, including the trailing slash if you want to gate only to your guestbook page. For example: `https://<your-project-url>.vercel.app/`

e. Click **Save**.

:::


## Enabling Hit Counter

### Enable Hit Counter

::: {.tabset}

# 1. Configure `next.config.ts`

::: {.callout}
# [Quickstart](/docs/quickstart) installs already include this configuration. 

[Install via npm](/docs/install) applications need the adjustments below.

:::

In your `next.config.ts` (or `next.config.js`), insert `FLAG_COUNTER` under `env`:

```typescript
const nextConfig: NextConfig = {
  env: {
    FLAG_COUNTER: process.env.FLAG_COUNTER,
  },
  // your existing options
};
```


# 2. Configure Environment Variables

In `.env.local` (for local development) or your Vercel environment variables (for cloud deployment):

1. Set **`FLAG_COUNTER=`** to `true`.

2. Scope the counter with **`FLAG_COUNTER_URL=`**. 

    - An empty `FLAG_COUNTER_URL` counts every `$pageview` in your PostHog project.
    - Each entered URL scopes to one exact page (`$host` + `$pathname`) — subpages are not included.
    - Always use a trailing slash on full URLs. 

    ```bash
    # Home board (this page only)
    FLAG_COUNTER_URL=https://<your-project-url>.vercel.app/

    # Nested board (this page only, not /guestbook/admin)
    FLAG_COUNTER_URL=https://<your-site>.vercel.app/guestbook/

    # Path only — same exact-page match; on Vercel this is also scoped to the production host
    FLAG_COUNTER_URL=/

    # Several exact pages
    FLAG_COUNTER_URL=https://example.com/,https://example.com/guestbook/
    ```


3. Optionally set **`FLAG_COUNTER_DATE=`** so unique `$pageview` visitors are counted only at or after that UTC time. Use the same timestamp format as PostHog SQL (`toDateTime`).

    ```bash
    # Exact UTC instant (same string as in HogQL)
    FLAG_COUNTER_DATE=2026-09-18 01:57:00

    # Midnight UTC on that calendar day
    FLAG_COUNTER_DATE=2026-09-16
    ```

    Leave it empty to count all time. Values that do not match those formats are ignored.

::: {.callout}
# `npm run dev` keeps the decorative fallback (000481) and does not call PostHog.

- Digits displayed are unique $pageview visitors from PostHog’s Query API. 
- In production the counter live-updates — poll `/api/hits` on load, then about every 15 seconds, from a fresh UTC-filtered Query API uniq (not PostHog’s default cached result). 

:::

:::

## Enable Web Tracking

1. Install [`posthog-js`](https://www.npmjs.com/package/posthog-js){.blank} to enable capture of client pageviews, clicks, and session replay:

    ```bash
    npm install posthog-js
    ```

2. Copy [`instrumentation-client.ts.example`](https://github.com/beck-chan/y2k-guestbook/blob/main/instrumentation-client.ts.example){.blank} as `src/instrumentation-client.ts` (or the project root if there is no `src/`):

    ```bash
    npx y2k-guestbook init-instrumentation
    ```

    ::: {.callout}
    # Next.js only loads the exact filename `instrumentation-client.ts`. Do not paste the PostHog HTML snippet into your layout.

    The example initializes PostHog only when `NODE_ENV === "production"`, with `person_profiles: "always"` which captures pageviews, clicks, and session replay via the SDK defaults.

    :::

3. From the PostHog dashboard's left sidebar, click **Settings**.

4. Under Products, select **Session replay**. Toggle ON:

    - **Record user sessions**
    - **Log capture**
    - **Canvas capture**

## Test Hit Counter & Tracking 

Development builds do not **send** `$pageview` events. To grow the count, build and serve (or use a Vercel deployment) so `instrumentation-client.ts` can capture:

```bash
# Linter check for errors
npm run lint
# Compile
npm run build
# Serve build 
npm run start
```

Confirm the hit counter matches an exact-page query (not a `$current_url LIKE`, which includes subpages):

1. From the PostHog dashboard's left sidebar, click **Product analytics**.

2. Click **+ New**, then select **SQL**.

3. Enter a SQL query that matches `FLAG_COUNTER_URL` and `FLAG_COUNTER_DATE`:

    ```sql
    -- Home: FLAG_COUNTER_URL=https://<your-project-url>.vercel.app/
    -- FLAG_COUNTER_DATE=2026-09-18 01:57:00
    SELECT uniq(distinct_id)
    FROM events
    WHERE event = '$pageview'
    AND properties.$host = '<your-project-url>.vercel.app'
    AND properties.$pathname = '/'
    AND timestamp >= toDateTime('2026-09-18 01:57:00', 'UTC')
    ```

    ```sql
    -- Nested board: FLAG_COUNTER_URL=https://example.com/guestbook/
    SELECT uniq(distinct_id)
    FROM events
    WHERE event = '$pageview'
    AND properties.$host = 'example.com'
    AND properties.$pathname = '/guestbook'
    AND timestamp >= toDateTime('2026-09-18 01:57:00', 'UTC')
    ```

    ```sql
    -- Several exact pages
    SELECT uniq(distinct_id)
    FROM events
    WHERE event = '$pageview'
    AND (
        (properties.$host = 'example.com' AND properties.$pathname = '/')
        OR (properties.$host = 'example.com' AND properties.$pathname = '/guestbook')
    )
    AND timestamp >= toDateTime('2026-09-18 01:57:00', 'UTC')
    ```

4. Click **Run**.

5. Confirm that the returned **Results** match your displayed hit counter.
