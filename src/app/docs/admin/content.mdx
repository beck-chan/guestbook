# Manage Admin Auth

<Setup />

## Managing Users

### Allow Admin Users

In the event you want to allow more users to manage your guestbook, you can allow-list their Google accounts as admin users.

Run the following command in your terminal to allow-list a Google account as your admin user:

```bash
npm install
npm run allow-admin -- example@gmail.com
```
::: {.callout }
The invited user will not receive an email invitation, and will need to authorize Google to connect on their first sign in.

:::

### Revoke Admin Users

Run the following command in your terminal to revoke admin access from a Google account:

```bash
npm install
npm run delete-admin -- example@gmail.com
```
::: {.callout }
Their access will be revoked after their most recent authentication session expires. 

:::

## Configure Unauthorized Access Error

If you want to customize the error message that is displayed to users who are not authorized to access the admin dashboard after they attempted to sign in, you can do so by editing the hardcoded message in [`AdminAuthErrorOverlay.tsx`](https://github.com/beck-chan/y2k-guestbook/blob/main/src/components/_shared/AdminAuthErrorOverlay.tsx){.blank}:


```typescript
        <h2 id="admin-auth-error-title" className="admin-auth-error-title">
          Oh no!
        </h2>
        <p id="admin-auth-error-body" className="admin-auth-error-body">
          The Google account you used to sign in isn&apos;t an administrator.
        </p>
        <button type="button" className="admin-auth-error-ok" onClick={dismiss}>
          Close
        </button>
```

## Publish Admin Auth Client

If you intend to serve your guestbook application to the general public, you may want to publish your Google OAuth client to production.

This will remove the generic `You're receiving this email because you used Sign in with Google to sign in to <your-project-url>.supabase.co on {timestamp}.` message when admin users authenticate into your guestbook dashboard, but may require a verification process depending on your Google Cloud project settings.
