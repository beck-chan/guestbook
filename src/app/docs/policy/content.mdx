## What We Collect

::: {.private}
| Data | Who | Purpose |
|---|---|---|
| Display name & message body | Anyone who comments | Displayed in posted comments |
| Optional email | Commenters | Visible to admins only — will not be used to contact you unless requested in your comment |
| IP address (stored hashed) | Commenters | Rate-limit abuse |
| Page-view / analytics events | Visitors | Traffic & hit-counter stats |
| Google account email & basic profile | Admins signing in with Google | Authenticate allow-listed users, send admins email notifications |
| Anonymous visitor cookie (poem {.heart}#) | Visitors who {.heart} like poems | Count one {.heart} like interaction per visitor per poem |

### Interactive API Library Reference

The [API Library](/docs/api/) on these documentation pages is a reference explorer. Values you type there are not guestbook comments and are not stored in the Site database.

If you use **Test Request**:

- A Supabase project ID you apply stays in your open browser tab only (`sessionStorage`). Closing the tab clears it.
- Anon keys and JSON Web Tokens (JWTs) you paste into request headers stay in the explorer until you reload or remount it. We do not save them.
- Send goes from *your* browser to *your* Supabase project. We do not proxy or log those requests.

:::

## Who Processes It

- **Google Cloud OAuth Client** — SSO for admins
- **Supabase** — Auth sessions and database storage
- **Vercel** — Serves the site on the cloud
- **PostHog** — Analytics tracking

::: {.callout}
We do not sell personal data.

:::

## Retention and Deletion

::: {.private}
- Guestbook comments (and optional emails) stay until an admin removes them or the database is cleared.
- Admin sessions use Supabase Auth (short-lived access tokens, long-lived refresh until sign-out or cookie clear).
- Admin Google account emails are stored in the admin allow-list until removed by a super-admin.
- Rate-limit keys are temporary.
- Analytics retention follows the PostHog project settings.

:::
