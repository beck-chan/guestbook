## Searching, Sorting & Filtering

::: {.callout}
Sorting, filtering, and searching stack.

:::

From the **comments** panel:

### Search & Sort

::: {.tabset}

# Search by Keyword

- Enter text into the `search` field and press enter to return comments with matching text.
- To clear a search, remove your text from the `search` field and press enter.

# Sort by Date

- Comments are sorted by `newest first` by default.
- Switch to `oldest first` to sort comments by the oldest comments first.

:::

### Filter

::: {.tabset}

# By Status

Shows all comments under **status** whether they are read or unread by default:

- Switch to `read` to show only read comments.
- Switch to `unread` to show only unread comments.

# By Contact

Shows all comments under **contact** whether or not an email was submitted by default:

- Switch to `has email` to show only comments with an email address.
- Switch to `no email` to show only comments without an email address.

# By Date Range

Select a date range to show comments submitted within that range using the date selectors.

::: {.callout}
Dates are shown in your local timezone.

:::

:::

## Mark Read & Unread

From the **comments** panel:

::: {.tabset}

# One Comment

In the bottom right-hand corner of a comment:

- Check **mark as read** to mark the comment as read.
- Uncheck **mark as unread** to mark the comment as unread.

# All Comments

Above all comments, click:

- **mark all read** to mark all comments as read.
- **mark all unread** to mark all comments as unread.

:::

::: {.callout}

Changes are saved automatically.

:::

## Edit & Delete

You can only edit and delete one comment at a time, and you can only edit comment bodies within the admin dashboard Settings. Under a comment, click:

::: {.tabset}

# Edit

To edit the comment body. Click away from the comment editor to save your changes.

### Advanced Edits

To edit display names or email addresses, you can use the [API](/docs/api):

1. {.get} `/comments` and copy the comment `id` values.
2. {.patch} `/comments` with the same authentication:
    - Under **Query Parameters**, set **key** `id` and **value** `eq.<comment-uuid>`. 
    - Under **Request Body**, send only the fields to change (`display_name` and/or `email`) — do not include `id`.

# Delete

To delete the comment. After you confirm the deletion, the comment will be removed from the list.

### Bulk Deletion

To delete several comments at once, you can use the [API](/docs/api):

1. {.get} `/comments` and copy the comment `id` values.
2. {.delete} `/comments`:
    - Under **Query Parameters**, set **key** `id` and **value** exactly like this, including the parentheses after `in.`:

    ```
    in.(<uuid-1>,<uuid-2>,<uuid-3>)
    ```

    `in.uuid-1,uuid-2` without `(` `)` returns `PGRST100`. No spaces after the commas. Leave the request body empty.

::: {.callout}
# An unfiltered delete is rejected (`21000`). 


Set **Prefer** to `return=representation` to return the rows that were removed.
