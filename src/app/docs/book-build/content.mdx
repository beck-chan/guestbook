# My custom install combines an interactive poetry volume with the guestbook commenting functionality:

- [`src/app/page.tsx`](https://github.com/beck-chan/guestbook/blob/main/src/app/page.tsx){.blank} loads poems, likes ({.heart}), the hit counter, and the first comments page, then renders [`PoetryDesk`](https://github.com/beck-chan/guestbook/blob/main/src/components/_desk/PoetryDesk.tsx){.blank}.

# Desktop

Above `768px`, [`.desk-desktop`](https://github.com/beck-chan/guestbook/blob/main/src/app/globals.css){.blank} shows an interactive animated 3D book volume. 

[`Book`](https://github.com/beck-chan/guestbook/blob/main/src/components/_desk/Book.tsx){.blank} drives open/close with [GSAP](https://gsap.com/){.blank} (`gsap` + `@gsap/react`).

# Mobile

At `max-width: 768px`, `.desk-desktop` is hidden and [`MobileReading`](https://github.com/beck-chan/guestbook/blob/main/src/components/_desk/MobileReading.tsx){.blank} a vertical snap scroller (`.mobile-reading`) takes the viewport.

### Poems

Poems are Markdown files that live under [`poetry/`](https://github.com/beck-chan/guestbook/tree/main/poetry){.blank}:

- [`loadPoems()`](https://github.com/beck-chan/guestbook/blob/main/src/lib/loadPoems.ts){.blank} reads that folder at request time, splits on `##` headings, and turns `*emphasis*` / `**strong**` into HTML. Each file becomes a `Poem` (`id` from the filename, `sections` for every heading).
- [`pickPoemIndex()`](https://github.com/beck-chan/guestbook/blob/main/src/lib/poems.ts){.blank} picks a random poem for the first paint, and a different one whenever the reader turns the page, ensuring no repeats in a row. 
- On each poem, a heart button calls [`togglePoemHeart`](https://github.com/beck-chan/guestbook/blob/main/src/lib/actions/hearts.ts){.blank} allowing visitors to like poems.

# Comments

[`CommentBubbles`](https://github.com/beck-chan/guestbook/blob/main/src/components/_shared/CommentBubbles.tsx){.blank} powers both the desktop inline guestbook and the mobile commenting overlay. Publicly displayed comments returns the `comments_public` table (`id`, `display_name`, `body`, timestamps — no email) via [`getPublicCommentsPage`](https://github.com/beck-chan/guestbook/blob/main/src/app/actions/comments.ts){.blank} by newest first. 

When users click **Submit**, the `submitComment` server action:

1. Requires a display name and comment body.
2. Enforces [`commentLengthError`](https://github.com/beck-chan/guestbook/blob/main/src/lib/commentLimits.ts){.blank} — name cap `128`, email cap `254`, and `comment_length` from settings for the body (default at `1000`).
3. Runs [`checkCommentProfanity`](https://github.com/beck-chan/guestbook/blob/main/src/lib/profanity.ts){.blank} ([`obscenity`](https://www.npmjs.com/package/obscenity){.blank} plus the admin allow-list).
4. Consumes [`consumeCommentRateLimit`](https://github.com/beck-chan/guestbook/blob/main/src/lib/rate-limit.ts){.blank} (`rate-limiter-flexible` over `DATABASE_URL`, keyed by a hash of [`clientIp()`](https://github.com/beck-chan/guestbook/blob/main/src/lib/clientIp.ts){.blank}). Burst and daily caps come from settings (default at `1` comment per `5` minutes, up to `2` per `24` hours). 
5. Inserts the submitted comment in the private `comments` table. Then `revalidatePath` for `/`, `/guestbook`, and the admin path, refreshing the page to show the new comment.


# Admin Dashboard

[`src/proxy.ts`](https://github.com/beck-chan/guestbook/blob/main/src/proxy.ts){.blank} (Next’s request proxy) refreshes the Supabase session on every matched path. Only `/admin` (or `NEXT_PUBLIC_GUESTBOOK_ADMIN_PATH`) is gated:

- No existing admin login session — redirects to `/admin/login`.
- Successful sign in but `app_metadata.role` is not `admin` — user is signed out and send home with `?admin_error=1`.
- Existing admin login session — redirects into the dashboard.

[`/admin/login`](https://github.com/beck-chan/guestbook/blob/main/src/app/admin/login/route.ts){.blank} starts Google OAuth. [`/auth/callback`](https://github.com/beck-chan/guestbook/blob/main/src/app/auth/callback/route.ts){.blank} exchanges the code, then [`resolveAdminSession`](https://github.com/beck-chan/guestbook/blob/main/src/lib/adminAuth.ts){.blank} calls `ensure_admin_role` (allow-list stamp) and refreshes the JWT so `role=admin` is on the cookie.

## Feature Flags

Flags are built on compile:

- [`src/lib/flags.ts`](https://github.com/beck-chan/guestbook/blob/main/src/lib/flags.ts){.blank} reads `process.env.FLAG_*` with `envFlag` (`true` / `1` vs `false` / `0` — unset uses the default) and `envString` for `FLAG_COUNTER_URL` and `FLAG_COUNTER_DATE`. 
- [`next.config.ts`](https://github.com/beck-chan/guestbook/blob/main/next.config.ts){.blank} lists those names under `env` so Next can inline them into client components.

# Public Guestbook

**`FLAG_PUBLIC`**

`flags.public` — default `false`.

Public guestbook home: rewrite `/` → `/guestbook` and redirect `/guestbook` → `/` so the board is the site root and the poetry desk is not served. Favicon fill switches from coral to dark green in [`src/app/icon.tsx`](https://github.com/beck-chan/guestbook/blob/main/src/app/icon.tsx){.blank}. GitHub links in [`flags.ts`](https://github.com/beck-chan/guestbook/blob/main/src/lib/flags.ts){.blank} (`releasesUrl`, `reportIssueUrl`) point at `y2k-guestbook` instead of `guestbook`. Docs landing subtitle, live OpenAPI catalog (`API_PUBLIC_URL`, `API_SERVICE_ROLE_KEY`, and `API_ANON_KEY`), Scalar **Test Request**, and `{.public}` / `{.private}` fences all follow this flag. Pages with `public: false` (this one included) 404 on a public deploy.


# Hit Counter

**`FLAG_COUNTER`**

`flags.hitCounter` — default `true`.

Shows the six-digit [`HitCounter`](https://github.com/beck-chan/guestbook/blob/main/src/components/_shared/HitCounter.tsx){.blank} on the desk (beside comments), the mobile cover, and `/guestbook`. Off: the component returns `null`.

Counts come from [`getUniqueVisitors()`](https://github.com/beck-chan/guestbook/blob/main/src/lib/uniqueVisitors.ts){.blank} (PostHog `$pageview` uniqueness, cached 60s). Non-production always shows the fallback in [`hitCount.ts`](https://github.com/beck-chan/guestbook/blob/main/src/lib/hitCount.ts){.blank}. In production the counter polls `/api/hits` and adds a one-time first-visit bonus from `localStorage`.

**`FLAG_COUNTER_URL`**

`flags.hitCounterUrl` — default empty string.

Comma-separated paths or URLs that scope the unique-visitor query. A path (for example `/` or `/guestbook`) matches `$pathname` exactly; a full URL substring-matches `$current_url`. Empty counts every `$pageview`. The value is part of the `unstable_cache` key, so changing it busts the cached count.

**`FLAG_COUNTER_DATE`**

`flags.hitCounterDate` — default empty string.

UTC instant (`YYYY-MM-DDTHH:mm:ssZ`, for example `2025-09-12T00:00:00Z`) that starts the unique-visitor query. Empty counts all time. Values that are not that exact format are ignored. The value is part of the `unstable_cache` key, so changing it busts the cached count.

# Documentation

**`FLAG_DOCS`**

`flags.docs` — default `true`.

Desk bookmarks and the mobile menu: **view docs** plus a short **admin login** ribbon. Off: the labeled bookmark is **admin login** only (no docs link). On the public guestbook page (`publicMode`), the labeled bookmark is **get started** and the short ribbon is **view docs**; if docs is off, those bookmarks are omitted.


`docsUrl` in the same file is the href (default `/docs`).

# FLAG_DOCSONLY

`FLAG_DOCSONLY` wins over `FLAG_PUBLIC`: docs-only redirects desk, guestbook, and admin into `/docs` and never loads settings or the guestbook theme.


`flags.docsOnly` — default `false`.

Serve only documentation. [`next.config.ts`](https://github.com/beck-chan/guestbook/blob/main/next.config.ts){.blank} redirects `/`, `/guestbook`, and `/admin` to `/docs`. [`src/app/layout.tsx`](https://github.com/beck-chan/guestbook/blob/main/src/app/layout.tsx){.blank} skips the settings fetch, guestbook theme, and admin-error overlay.

`npm run docs` sets `FLAG_DOCSONLY=true` on that process via [`scripts/docs-dev.mjs`](https://github.com/beck-chan/guestbook/blob/main/scripts/docs-dev.mjs){.blank} (overrides `.env.local`). Local preview only — do not set this on Vercel.
