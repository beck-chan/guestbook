### Poems

Poems are Markdown files that live under [`poetry/`](https://github.com/beck-chan/guestbook/tree/main/poetry){.blank}:

- [`loadPoems()`](https://github.com/beck-chan/guestbook/blob/main/src/lib/loadPoems.ts){.blank} reads that folder at request time, splits on `##` headings, and turns `*emphasis*` / `**strong**` into HTML. Each file becomes a `Poem` (`id` from the filename, `sections` for every heading).
- [`pickPoemIndex()`](https://github.com/beck-chan/guestbook/blob/main/src/lib/poems.ts){.blank} picks a random poem for the first paint, and a different one whenever the reader turns the page, ensuring no repeats in a row. 
- On each poem, a heart button calls [`togglePoemHeart`](https://github.com/beck-chan/guestbook/blob/main/src/lib/actions/hearts.ts){.blank} allowing visitors to like poems.

# Row-Level Security

The schema applied by running [`scripts/schema.sql`](https://github.com/beck-chan/guestbook/blob/main/scripts/schema.sql){.blank} enables row-level security on every public table — `is_admin()` is true only when the JWT has `app_metadata.role = 'admin'` (stamped from the allow-list at signup, not from editable `user_metadata`).

| Table | `anon` | Admin (`authenticated` + `is_admin()`) |
| --- | --- | --- |
| `comments` | {.insert} | {.select}, {.insert}, {.update}, {.delete} |
| `guestbook_settings` | {.select} | {.select}, {.update} |
| `admin_allowlist` | none | none |
| `poem_hearts` | none | none |

- `comments` has no public {.select}, so emails stay on the private table. Visitors read the `comments_public` view instead (`id`, `display_name`, `body`, timestamps).
- `guestbook_settings` is a singleton (`id = 1`) — no {.insert} or {.delete} policies. {.select} is granted to `anon` and `authenticated`.
- `admin_allowlist` has RLS on with no policies, so `anon` / `authenticated` cannot read or write. `service_role` bypasses RLS (and still needs table grants). Auth’s `before-user-created hook` reads it as `supabase_auth_admin`.
- `poem_hearts` has no table policies. Likes go through the security-definer RPCs `toggle_poem_heart` and `poem_heart_state`. Public counts come from `poem_heart_counts` and `poem_heart_total`.

# Admin Notifications

Database webhooks `POST` into two [Supabase Edge Functions](https://github.com/beck-chan/guestbook/tree/main/supabase/functions){.blank} (`verify_jwt = false` in [`supabase/config.toml`](https://github.com/beck-chan/guestbook/blob/main/supabase/config.toml){.blank}):

-  Both check `NOTIFY_WEBHOOK_SECRET` (`x-notify-webhook-secret` or Bearer), then no-op unless the Edge secret `FLAG_NOTIF` is `true` / `1`. 
- Recipients come from `admin_allowlist` via the service role ([`loadAllowlist()`](https://github.com/beck-chan/guestbook/blob/main/supabase/functions/_shared/allowlist.ts){.blank}).

| Function | Trigger |
| --- | --- |
| [`notify-admins`](https://github.com/beck-chan/guestbook/blob/main/supabase/functions/notify-admins/index.ts){.blank} | Table webhooks on `admin_allowlist`, `comments`, `guestbook_settings`, and `poem_hearts` |
| [`on-user-created`](https://github.com/beck-chan/guestbook/blob/main/supabase/functions/on-user-created/index.ts){.blank} | `auth.users` {.insert} — the new address plus the existing admin list |

[`notify-admins`](https://github.com/beck-chan/guestbook/blob/main/supabase/functions/notify-admins/index.ts){.blank} maps webhook `table` and `type` onto Markdown templates in [`_shared/templates/`](https://github.com/beck-chan/guestbook/tree/main/supabase/functions/_shared/templates){.blank}:

| Table | Events | Recipients |
| --- | --- | --- |
| `admin_allowlist` | {.insert}, {.delete} | The added/removed address, and the admin list |
| `comments` | {.insert}, {.update}, {.delete} | Admin list |
| `guestbook_settings` | {.update} | Admin list |
| `poem_hearts` | {.insert}, {.delete} | Admin list ({.heart} / unheart) |

- Comment {.update} only mails when `display_name`, `email`, or `body` changed. 
- Settings {.update} skips `id` and `updated_at`.

Mail goes out through [`gmail.ts`](https://github.com/beck-chan/guestbook/blob/main/supabase/functions/_shared/gmail.ts){.blank} — Gmail API with a refresh token, From `Poetry Guestbook <GMAIL_USER>`.

# Comments

[`CommentBubbles`](https://github.com/beck-chan/guestbook/blob/main/src/components/_shared/CommentBubbles.tsx){.blank} powers both the desktop inline guestbook and the mobile commenting overlay. Publicly displayed comments returns the `comments_public` table (`id`, `display_name`, `body`, timestamps — no email) via [`getPublicCommentsPage`](https://github.com/beck-chan/guestbook/blob/main/src/app/actions/comments.ts){.blank} by newest first. 

When users click **Submit**, the `submitComment` server action:

1. Requires a display name and comment body.
2. Enforces [`commentLengthError`](https://github.com/beck-chan/guestbook/blob/main/src/lib/commentLimits.ts){.blank} — name cap `128`, email cap `254`, and `comment_length` from settings for the body (default at `1000`).
3. Runs [`checkCommentProfanity`](https://github.com/beck-chan/guestbook/blob/main/src/lib/profanity.ts){.blank} ([`obscenity`](https://www.npmjs.com/package/obscenity){.blank} plus the admin allow-list).
4. Consumes [`consumeCommentRateLimit`](https://github.com/beck-chan/guestbook/blob/main/src/lib/rate-limit.ts){.blank} (`rate-limiter-flexible` over `DATABASE_URL`, keyed by a hash of [`clientIp()`](https://github.com/beck-chan/guestbook/blob/main/src/lib/clientIp.ts){.blank}). Burst and daily caps come from settings (default at `1` comment per `5` minutes, up to `2` per `24` hours). 
5. Inserts the submitted comment in the private `comments` table. Then `revalidatePath` for `/`, `/guestbook`, and the admin path, refreshing the page to show the new comment.


# Admin Dashboard

[`src/proxy.ts`](https://github.com/beck-chan/guestbook/blob/main/src/proxy.ts){.blank} (Next’s request proxy) refreshes the Supabase session on every matched path. Only `/admin` (or `NEXT_PUBLIC_GUESTBOOK_ADMIN_PATH`) is gated:

- No existing admin login session — redirects to `/admin/login`.
- Successful sign in but `app_metadata.role` is not `admin` — user is signed out and send home with `?admin_error=1`.
- Existing admin login session — redirects into the dashboard.

[`/admin/login`](https://github.com/beck-chan/guestbook/blob/main/src/app/admin/login/route.ts){.blank} starts Google OAuth. [`/auth/callback`](https://github.com/beck-chan/guestbook/blob/main/src/app/auth/callback/route.ts){.blank} exchanges the code, then [`resolveAdminSession`](https://github.com/beck-chan/guestbook/blob/main/src/lib/adminAuth.ts){.blank} calls `ensure_admin_role` (allow-list stamp) and refreshes the JWT so `role=admin` is on the cookie.

# Hit Counter

[`src/app/page.tsx`](https://github.com/beck-chan/guestbook/blob/main/src/app/page.tsx){.blank} and [`src/app/guestbook/page.tsx`](https://github.com/beck-chan/guestbook/blob/main/src/app/guestbook/page.tsx){.blank} both call [`getUniqueVisitors()`](https://github.com/beck-chan/guestbook/blob/main/src/lib/uniqueVisitors.ts){.blank} (PostHog `$pageview` uniqueness, cached 60s) and pass the number into [`HitCounter`](https://github.com/beck-chan/guestbook/blob/main/src/components/_shared/HitCounter.tsx){.blank}:

- [`HitCounter`](https://github.com/beck-chan/guestbook/blob/main/src/components/_shared/HitCounter.tsx){.blank} is a client component. 
- When `FLAG_COUNTER` is off it returns `null`. 

Development always shows the static [`FALLBACK_HIT_COUNT`](https://github.com/beck-chan/guestbook/blob/main/src/lib/hitCount.ts){.blank} (`481`). In production it:

1. Renders the server count.
2. Adds a one-time first-visit bonus from `localStorage` (`guestbook.hit-counted`).
3. Polls [`/api/hits`](https://github.com/beck-chan/guestbook/blob/main/src/app/api/hits/route.ts){.blank} every `45` seconds and never lets the displayed value drop.

HogQL scoping (`FLAG_COUNTER_URL`, `FLAG_COUNTER_DATE`) is documented under **Hit Counter** in [Feature Flags](#feature-flags).

## Feature Flags

Flags are built on compile:

- [`src/lib/flags.ts`](https://github.com/beck-chan/guestbook/blob/main/src/lib/flags.ts){.blank} reads `process.env.FLAG_*` with `envFlag` (`true` / `1` vs `false` / `0` — unset uses the default) and `envString` for `FLAG_COUNTER_URL` and `FLAG_COUNTER_DATE`. 
- [`next.config.ts`](https://github.com/beck-chan/guestbook/blob/main/next.config.ts){.blank} lists those names under `env` so Next can inline them into client components.

# Public Guestbook

### `FLAG_PUBLIC`

Allows diversion of the guestbook to a public page instead of the landing with the poetry volume. 

Used to deploy to the public version of the site at [https://y2k-guestbook.vercel.app/](https://y2k-guestbook.vercel.app/){.blank}:

- Homepage is the full page guestbook instead of the landing with the poetry volume.
- Favicon is dark green instead of coral.
- GitHub "Releases" and "Report Issue" links point at `y2k-guestbook` instead of `guestbook`.
- Documentation landing subtitle, live OpenAPI explorer, and `{.public}` / `{.private}` fences all follow this flag. 
- Documentation pages with `public: false` in their YAML frontmatter (like this one) do not display in the side navigation and do not exist on the public version of the site.


# Hit Counter

### `FLAG_COUNTER`

When set to `true`, enables display of the [`HitCounter`](https://github.com/beck-chan/guestbook/blob/main/src/components/_shared/HitCounter.tsx){.blank}. Counts come from [`getUniqueVisitors()`](https://github.com/beck-chan/guestbook/blob/main/src/lib/uniqueVisitors.ts){.blank} (PostHog `$pageview` uniqueness, cached 60s). Development mode always shows the static fallback in [`hitCount.ts`](https://github.com/beck-chan/guestbook/blob/main/src/lib/hitCount.ts){.blank}. In production the counter polls `/api/hits` and adds a one-time first-visit bonus from `localStorage`.

### `FLAG_COUNTER_URL`

Comma-separated paths or URLs that scope the unique-visitor query. A path (for example `/` or `/guestbook`) matches `$pathname` exactly — a full URL substring-matches `$current_url`. Empty counts every `$pageview`. 

### `FLAG_COUNTER_DATE`

UTC instant (`YYYY-MM-DDTHH:mm:ssZ`, for example `2025-09-12T00:00:00Z`) that starts the unique-visitor query. Empty counts all time. Values that are not that exact format are ignored. 

# Documentation

### `FLAG_DOCS`

When set to `false`, hides the **View Docs** link from view, and swaps in the **Admin Login** link instead. Only used for v1 of the public deployment when I was still completing the documentation so nobody stumbled upon the incomplete guides.

### `FLAG_DOCSONLY`

Serves only the documentation instead of the full guestbook application for a lighter weight preview when authoring docs. Can be called with `npm run docs` which sets `FLAG_DOCSONLY=true` on that process via [`scripts/docs-dev.mjs`](https://github.com/beck-chan/guestbook/blob/main/scripts/docs-dev.mjs){.blank} (overrides `.env.local`).
