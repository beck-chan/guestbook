# MDX Reference

Copy `example/page.tsx` next to a `content.mdx` into a directory named for the page URL slug.

## YAML Frontmatter

```yaml
---
subtitle: Set an optional subtitle
search: false # Hide page from docs search
public: false # Hide page when FLAG_PUBLIC=true

# h1 sets the page title and browser tab
---
```

## Single-Sourcing

Shared prose lives in `_snippets/`. Import a snippet to use it on a page:

```markdown
import Example from "../_snippets/example.mdx"

<Example />
```

::: {.callout}
<Example />
:::

Leave YAML and `# h1` on the host page. Snippet headings do not appear in the host page table of contents by default — merge the `toc` exports in `page.tsx` if they should:

```typescript
import Guide, { toc as guideToc } from "./content.mdx";
import Example, { toc as exampleToc } from "../_snippets/example.mdx";

const toc = [...guideToc, ...exampleToc];
```

## Content

### Headings

The sticky note table of contents are built from `##` and `###` headings.

### Callouts

::: {.callout}

# A `#` heading inside a callout is styled like `###` and does not appear in the table of contents.

Use a `::: {.callout} :::` for a note that should sit apart from the main text.

:::

### Text & Links

::: {.columns}

::: {.80}
You can write **bold** and *italic* in the same sentence as the surrounding copy, and add [links](url) as usual.

Append `{.button}` to a markdown link for a bordered button. Append `{.blank}` to open a link in a new tab.

:::

## Layouts

### Tabsets

::: {tabset}

# one

`::: {tabset} :::` splits on `# h1` headings. Those headings become tab labels, not page titles.

# two

A `#` heading inside a nested callout stays in the callout.

::: {.callout}
# Callout title

This is not a third tab.
:::

:::
